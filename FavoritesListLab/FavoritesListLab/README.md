## 🛠 Technical Requirements & Features
- **Theme:** Sports & Martial Arts.
- **Data Model:** A dedicated `FavoriteItem` struct containing unique items with title, subtitle, image, and rating (0 to 5).
- **Custom Cell:** Designed a separate `FavoriteCell` subclass mapped directly to the prototype cell in `Main.storyboard`.
- **UI Elements:** `UIImageView`, `UILabel`, and horizontal `UIStackView` with `SF Symbols` for dynamic star ratings.
- **Auto Layout:** Fully implemented within `Main.storyboard` using constraints and stack views.

## ⚙️ How to Run
1. Clone the repository.
2. Open the project in **Xcode**.
3. Select a simulator (`iPhone SE` or `iPhone 16 Pro Max`) and press **`Cmd + R`** to run.
